Account and portfolio setup

A beginner's guide to GitHub, Behance and a free website.

1. Create a GitHub account

  1. Visit GitHub sign up.
  2. Use your email, verify it and set a strong, unique password.
  3. Turn on two-factor authentication in your account settings.
  4. Create a repository to keep your starter projects.

2. Create a Behance portfolio

  1. Go to Behance.
  2. Sign in or create an Adobe account.
  3. Add a clear profile name and one original project with a description.
  4. Publish only work you own or are allowed to show.

3. Publish a free website

  1. Keep your website's index.html at the top of your project folder.
  2. Open Netlify Drop and sign in.
  3. Drag your unzipped website folder into the upload area.
  4. Share the live link, then add it to Google Search Console so it can be found on Google.

Never share your passwords, verification codes or recovery details with anyone.
